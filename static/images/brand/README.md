# GardenHub brand assets

GardenHub uses the approved **Additional Concept 4 — Framed Living System** identity. The mark combines an outer circular frame, landscape contours, a central point, and a rooted lower structure.

See the repository’s [official brand reference](../../../docs/BRAND.md) for colours, size guidance, and approved usage. This directory is the single canonical location for production logo assets.

| Asset | Intended use |
| --- | --- |
| `gardenhub-logo.svg` | Primary full lockup on light backgrounds |
| `gardenhub-logo-reversed.svg` | Full lockup on deep green or other dark backgrounds |
| `gardenhub-mark.svg` | Primary icon-only mark at normal UI sizes |
| `gardenhub-mark-reversed.svg` | Light icon-only mark on dark backgrounds |
| `gardenhub-mark-small.svg` | Simplified icon-only mark below 32 px |
| `gardenhub-favicon.svg` | Browser favicon |
| `gardenhub-app-icon.svg` | Square launcher / installable-app tile |
| `gardenhub-apple-touch-icon.png` | 180 px raster export for Apple home-screen metadata |
| `gardenhub-logo-monochrome-dark.svg` | One-colour dark lockup |
| `gardenhub-logo-monochrome-light.svg` | One-colour light lockup |

Keep the supplied SVG aspect ratio and clear space. Use the simplified mark at tiny sizes; do not add leaves, sprouts, flowers, or other symbols to the identity.

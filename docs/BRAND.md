# GardenHub Brand Reference

GardenHub uses the **Framed Living System** identity. The mark combines a circular frame with a central point, landscape/contour lines above, and a rooted structure below.

The name is always written **GardenHub**. Older spellings, temporary marks, and experimental logo concepts should not be used in current product work.

## Using the logo

Use the full logo on light or neutral backgrounds and the reversed or light monochrome version on dark backgrounds.

The full lockup works best from 120 CSS px wide. Below that, use the icon-only mark. At sizes below 32 px, use the simplified mark; browser contexts should use the favicon asset.

Keep the original SVG proportions and leave enough clear space around the circular frame. Do not redraw the mark, alter the wordmark, add decorative leaves or sprouts, or create duplicate versions of the official assets.

Earlier logo concepts can be kept as design history, but they should be clearly marked as exploratory or superseded and should not be used as current GardenHub branding.

# Legacy Development Files

Files in this folder are retained for historical reference. They are not part
of the active GardenHUB runtime and must not be used as supported application
entry points.

- `Main.py` is an obsolete exploratory menu that imports removed menu code and
  still contains placeholder actions.
- `historic_sensor.py` is an obsolete history script that queries weather data
  using columns that do not exist in the current schema.

These files are intentionally preserved unchanged and may reference obsolete
schemas, modules, or workflows.

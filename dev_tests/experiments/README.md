# Future Experiments

This folder contains development experiments that are not part of the active
GardenHub runtime or supported production features.

- `ml_pipeline.py` is a placeholder machine-learning data pipeline whose SQL
  and schema assumptions do not match the current application.
- `test_perenual.py` explores the external Perenual plant API.
- `test_trefle.py` explores the external Trefle plant API.

The experiments are retained for possible future work. Their schemas, APIs,
credentials, and dependencies may not match the current application, and they
have not been modernized or repaired as part of this organization phase.
